# How C-Play opens and interprets media files

You can open various formats for video, images and audio directly by using "Open file".

However, while C-Play is this flexible, it has been designed to use combinations of video, images and audio during a show.

For insight into how video is handled, see:
 - [Video file guide](/media/video)

And images, either as primary sources, backgrounds or overlays, see:
 - [Image file guide](/media/images)

 Both video and images can be mapped onto physical objects in multiple ways, see:
 - [Video & Image Mapping Modes](/media/mapping)

 Audio can be loaded without video, but is usually combined inside the video or as adjacent files. See:
  - [Audio file guide](/media/audio)


## C-Play file structures

You can save a media bundle, based on the content specified above, to make C-Play load everything correctly from one file. See this guide to learn how to make these:
 - [CPlayfile](/media/cplayfile)

 Also, multiple cplayfiles can be ordered in a playlist, through this guide:
 - [CPlaylist](/media/cplaylist)

  From C-Play v2.1, you can build slides with multiple media layers which can be viewed as an immersive presentation, through this guide:
 - [CPlayPres](/media/cplaypres)
