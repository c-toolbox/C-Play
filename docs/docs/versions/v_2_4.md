# What's new in C-Play 2.4

C-Play 2.4 is currently in **beta**. It will become the regular release once testing is done. The guides linked from this page always describe the latest version of C-Play.

Version 2.4 is about three things:

* **Run your show from anywhere.** Use a tablet, a phone or a second screen to step through slides, run a playlist or place layers.
* **Bring in more content.** Add YouTube videos, cameras and capture cards, remote guests over the internet, and live streams from a media server.
* **Make slides come alive.** Add PowerPoint-style entrance and exit effects, smooth animations, and green-screen keying and color correction.

## Run your show from a tablet or phone

C-Play now includes three web pages, called **views**, that you can open on any device on the same network as the master computer. Nothing needs to be installed: open the address in a browser, or open the view straight from C-Play on one of the master's screens.

To get started, open **Views** in the C-Play menu bar and pick a view. Then choose **Open in default browser**, or choose **Copy address for other devices** and open the address on your tablet or phone.

![The start page links to all three views](/assets/ui/web_start_page.png)

The **start page** links the three views, so you only need to remember one address. In every view, the C-Play logo in the top left corner opens a menu where you can switch to another view.

### Presenter view: slides, notes and a timer

![Presenter view](/assets/ui/presenter_view.png)

The presenter view is for running a presentation. It shows:

* the current slide and the next slide
* your **speaker notes**, which you can edit in the view
* a clock and a presentation timer
* every slide in a strip at the bottom, so you can jump to any slide

You can also **skip slides** you don't want to show today. **Next** and **Previous** then pass over them.

### Movie view: playlist, sections and cues

![Movie view with the cue list](/assets/ui/movie_view_live.png)

The movie view is for running a playlist. You can see what is on air, jump between sections, change the volume and fade the picture in and out.

* In **Live** mode, everything you click happens in C-Play right away.
* In **Prepare** mode, you set up the next item, section and start time without disturbing what is playing. When you are ready, press **Take → Live**.
* **Transition** fades out, loads the next item, then plays and fades in, all with one button.
* A **cue list** lets you prepare a whole show and fire it cue by cue with **GO**, for example with a presentation clicker.

### Layer view: place your layers on the dome

![Layer view](/assets/ui/web_layer_view.png)

The layer view is for preparing a presentation. Drag layers to where you want them on the dome, the screen or the sphere. Resize them, fade them in or out, and set their volume. Every change shows up in C-Play right away.

## New content you can add

Several new layer types appear in the **Add new layer** dialog of the presentation tool.

![The layer types in the Add new layer dialog](/assets/ui/layer_types.png)

### YouTube videos

![Adding a YouTube layer](/assets/ui/layer_add_youtube.png)

Paste a YouTube link (a normal video, a Short or a youtu.be link) into a **YouTube** layer, and it plays like any video file. You get play/pause, a seek slider, looping and the other player controls.

Every computer in the cluster needs the free [yt-dlp](https://github.com/yt-dlp/yt-dlp) tool installed. See [YouTube playback and yt-dlp](/media/layers#youtube-playback-and-yt-dlp).

### Cameras and capture cards

The new **DirectShow** layer (Windows) shows a live picture from a webcam, a camera or a capture card. You pick the video device and, if you want sound, an audio device. A DirectShow layer can also play image and video files using the decoders that come with Windows.

**Read more:** [DirectShow](/media/layers#directshow)

### Remote guests over the internet

![VDO.Ninja Arena Rooms](/assets/ui/vdo_ninja_rooms.png)

The new **WebRTC** layer shows a live video stream from anywhere, with very little delay. Together with the free [VDO.Ninja](https://vdo.ninja) service, remote guests can share their camera or screen from a normal web browser, and their picture appears in your dome.

With **VDO.Ninja Arena Rooms** (*Settings → VDO.Ninja Arena Rooms...*), you can set up a room with several guest slots. C-Play creates the invite links for you, and **Add All As Layers** adds every guest to your presentation in one step.

**Read more:** [WebRTC](/media/layers#webrtc), [VDO.Ninja → C-Play](/system-integration/vdo-ninja)

### Live streams from a media server

![MediaMTX streams](/assets/ui/mediamtx_streams.png)

If you use a [MediaMTX](https://github.com/bluenviron/mediamtx) streaming server, C-Play can list the streams it has right now. Choose one and add it as a layer, without typing any addresses.

**Read more:** [MediaMTX streams](/system-integration/mediamtx)

### Several videos playing together

![Multi-video composer](/assets/ui/multivideo_composer.png)

A **multi-video** composition plays several videos at the same time, perfectly in sync, with a different video on each computer in the cluster. One use is separate left-eye and right-eye videos for a stereoscopic dome.

**Read more:** [Multi-video composition](/media/cplaymulti)

## Make your slides come alive

### Entrance and exit effects

![The Effects pane](/assets/ui/effects_entrance.png)

As in PowerPoint, layers can now appear and disappear with effects: Fade, Wipe, Fly, Zoom, Spin, Particles and more. Open the **Effects** pane with the star button below the layer list.

Each effect can start **on click**, **with the previous effect** or **after the previous effect**. That way a single slide can reveal its content step by step each time you press **Next**.

**Read more:** [Animations](/media/cplaypres#animations-c-play-v24-and-newer)

### Smoother animations

Slide timeline animations can now ease in and out instead of moving at a constant speed, and they can also animate a layer's size and position on the dome.

### Green screen and color correction

![Post process effects](/assets/ui/effects_post_process.png)

Every layer can have **post process effects**: chroma key (green screen), luma key, color correction, tint, blur, sharpen, pixelate and soft edges. For example, you can remove the green background from a live camera so the presenter appears to stand in your content.

**Read more:** [Post process effects](/media/layer-operations#post-process-effects)

## Sound that follows the picture

A new **Audio mapping** dialog, opened from the audio settings, can move the sound of a live layer to the speakers closest to where the layer is shown. Move a camera layer to the left side of the dome, and its sound follows. Stereo sources can also be mixed up to 5.1 (or down again) automatically.

**Read more:** [Audio mapping](/settings/audio_mapping)

## New ways to look at your show

![The Views menu](/assets/ui/views_master_view.png)

A new **Views** menu collects the ways to view your show on the master screen:

* **Fisheye view.** See your dome content as a flat circle, the way a fulldome image looks.
* **Sphere view.** See your content on the outside of a globe and turn it with the mouse.
* **3D view improvements.** You can zoom, move layers with Ctrl + click, and save your favourite camera position.

**Read more:** [Views](/playback/views)

## Share C-Play with other systems

* **NDI output.** C-Play can send its picture over the network as NDI, so you can use it in other programs such as OBS Studio for recording or live streaming. Each layer can also be sent as its own NDI source. See [NDI output](/system-integration/ndi-output).
* **Stream layers to the nodes.** A layer can be played once on the master and sent to all nodes, instead of every node playing its own copy. This makes heavy content easier for the nodes. See [Streaming layers from master to nodes](/playback/node-streaming).
* **Master-only and nodes-only layers.** Choose whether a layer is shown on the master only (for example a control layer or an NDI output) or on the nodes only (to save work on the master). See [Master-only layers](/system-integration/ndi-output#master-only-layers-sync-button) and [Receive on the nodes only](/media/layer-operations#receive-on-the-nodes-only).

## Smaller improvements

* **Synchronized start.** A newly loaded video starts only when every computer in the cluster has loaded it, so all screens begin together.
* **Missing files.** The Inspect view now tells you when a layer's file is missing on this computer, and a button opens its folder.
* **Background color.** Use a plain background color instead of a background image. See [Image settings](/settings/image).
* **Mute everything.** The mute button now also mutes live layers.
* **Audio level meter.** Live layers show an audio meter in the Inspect view.
* **Smoother node fades.** The node windows can fade to black and hide, which works on every system. See [Window & UI](/settings/window_and_ui#node-window-behavior).
* **Renamed button.** The *Layer View* button below the layer list is now called **Inspect**.
* **Logging window.** A new window helps you see what is happening when something does not play smoothly.

## For technicians

Some features depend on how C-Play was built and set up:

* **Web views** are included by default (`BUILD_CPLAY_WEB_VIEWS`). Opening them inside a C-Play window needs Qt WebView (`BUILD_CPLAY_WITH_WEBVIEW`); without it they open in a browser window. The HTTP server has to be on in `data/http-server-conf.json`. See [Build from code → Web views](/build/web-views).
* **WebRTC layers, VDO.Ninja Arena Rooms and movie view pictures** need a build with WebRTC (`BUILD_CPLAY_WITH_WEBRTC`, off by default).
* **DirectShow layers** are included in Windows builds by default (`BUILD_CPLAY_WITH_DIRECTSHOW`).
* **YouTube layers** need `yt-dlp` on every cluster machine.
* **Several clusters** can link their web view start pages through `clusters` in `data/http-server-conf.json`.
* **Per-machine streams and devices** can be set in `data/predefined-streams.json` and `data/predefined-directshows.json`.
* **Other changes:** optional framesync for tighter node synchronization, OpenGL 4.6 with the latest SGCT and OpenXR support, per-file mpv options in playfiles, a node window opacity mode setting, and node windows that keep their transparency when they get focus.
