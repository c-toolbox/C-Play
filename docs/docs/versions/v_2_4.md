# C-Play Version 2.4

This is the landing page for the documentation of C-Play Version 2.4, from the application itself. This version is currently in beta on a separate development branch; when it becomes the latest release, the continuously updated guides below apply to this release.

This update introduces NDI output — C-Play can now publish its main video and individual presentation layers as NDI sources that other applications (e.g. OBS Studio) can receive over the network. It also adds multi-video composition for nodes, master-only layers, and several 3D view improvements.

#### NDI output
C-Play v2.4 can send its own video out through NDI: in addition to the full player output (main video), each presentation layer can be published as an independent NDI source from the master. Video only for now. See [C-Play -> NDI output](/system-integration/ndi-output).

#### Multi-video composition (*.cplaymulti)
Multiple videos can play simultaneously on cluster nodes, all time-synced to a single master reference video, with per-node file paths and different rendering mappings (e.g. left/right eye for stereoscopic domes). See [Multi-video composition](/media/cplaymulti).

#### Master-only layers
Layers in the layer view can now be marked to exist on the master only — not synced to the nodes — with a new **Sync** button. This is useful for example for layers whose purpose is NDI output, or control-only layers. A new user interface setting hides such layers from the 3D view by default. See [Window & UI](/settings/window_and_ui) and [C-Play -> NDI output](/system-integration/ndi-output#master-only-layers-sync-button).

#### 3D view improvements
Zoom in the dome render view, moving selected layers with Ctrl + left mouse click, and saving the camera position/rotation as startup values (double-clicking restores the saved pose). The header taskbar view-mode button is now a menu that selects how the master view renders: only the main video, all layers in a 3D view with a perspective camera, or all layers in a 3D view with a fisheye camera — a new optional **180° fisheye (fulldome) projection** that shows your dome/sphere content as a flat circular image. See [Views](/playback/views#fisheye-180-projection-fulldome) and [Window & UI](/settings/window_and_ui).

#### Other changes
* Optional framesync system for tighter synchronization between nodes.
* Per-file mpv options in playfiles, for example to select if a video should decode alpha or not.
* Optional guessing of grid mode when dragging media onto the layers list.
* Updated to OpenGL 4.6 and latest SGCT, with OpenXR support.
