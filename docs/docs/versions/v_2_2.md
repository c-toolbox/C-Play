# C-Play Version 2.2 

This is the landing page for the documentation of C-Play Version 2.2, from the application itself.

This version updated the SGCT backend and dropped XML cluster configuration support. Use JSON configurations, as described in the [cluster configuration guide](/setup/sgct). The linked guides describe the current application and may include settings unavailable in v2.2.
